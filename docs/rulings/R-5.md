## Context
A shared library turns into entropy when nobody knows who uses what at which version, and when consumers copy instead of import.

## Decision
The registry is derived, never hand-kept. config/consumers.txt is the one hand-kept list and says only where to look. `make consumers` reads each repo's go.mod through gh and code-searches the stamp `go-foundation-copy: <unit>@<sha>`, and writes CONSUMERS.md: per unit and repo, current / behind / copy, and unused units. UNITS.md is generated from unit.json. How to adopt: every unit README has the headings Install / Wire / Configure / Extension points / Do not, and every release ships adoption notes with detects. No forks: extend through options and interfaces; a change one consumer needs is made upstream; a copy needs the stamp and a backlog row to remove it.

## Consequences
`make consumers` needs the network, so it runs at every unit release, never in make check. A copy stays visible until it is replaced by an import.
