## Context
A library whose go line is above a consumer's toolchain breaks that consumer. Measured 2026-11-08 across the consumer list: the lowest is 1.25.5, the rest 1.26.x and 1.27.x (a2ahub 1.26.10, sporo 1.26.5).

## Decision
config/go-floor holds the floor (1.25.0). No unit's go line exceeds it. A unit raises it only for a language or stdlib feature it needs, and never above the lowest active consumer.

## Consequences
units-check refuses a go line above the floor.
