## Context
Shared Go code for every project: primitives (clock, retry, ids) and whole modules (auth with its internal packages). An import path is permanent, and a primitive can grow into a module.

## Decision
One unit is one capability, one directory at the repo root and one Go module (`github.com/ydnikolaev/go-foundation/<id>`). There is no category directory in the path; `kind` (primitive | module) is metadata in `<id>/unit.json`. Each unit has its own go.mod, so a consumer pulls only that unit's dependencies. go.work is for local development across units only. Unit to unit is a plain `require`, declared in config/modules.ini `deps.<id>`.

## Consequences
`make units-check` refuses a go.mod dir without unit.json, an id that is not the dir, and a module path outside the root. Renaming a unit is a new unit plus a deprecation.
