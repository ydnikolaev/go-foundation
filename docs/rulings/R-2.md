## Context
Units version independently in one repo.

## Decision
A release is a path-prefixed tag `units/<id>/vX.Y.Z`: Go requires the tag prefix to be the module's directory (R-1). A unit stays at v0 while `stability: experimental`; v1 makes it `stable`. A breaking change after v1 moves the module path to `units/<id>/vN`. scripts/unit-release.sh cuts a tag only on a clean tree whose `make check-full` passed, and every release ships `units/<id>/releasenotes/<version>.yaml` in the adoption schema (what the consumer changes, with a detect).

## Consequences
Consumers upgrade one unit at a time; a release without notes is refused.
