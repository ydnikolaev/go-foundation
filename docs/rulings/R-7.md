## Context
A unit release ends with a tag push. Until now every push was owner-gated, so each release waited on the owner after the gate had already judged the tree. The owner was asked directly on 2026-11-08: may the go-foundation session push unit release tags itself once scripts/unit-release.sh is green?

## Decision
Yes. After `scripts/unit-release.sh <id> <X.Y.Z>` exits 0 (a clean tree, release notes present, `make check-full` green, the annotated tag cut) and `make public-scan` passes, the session pushes that one tag: `git push origin units/<id>/vX.Y.Z`. The grant covers unit release tags only. Pushing main, a force-push, deleting or moving a tag, and changing the visibility stay with the owner.

## Consequences
A unit release no longer waits on the owner. A tag on a public repo is cached by the Go proxy and the checksum database at first fetch and can never be withdrawn, which is why the push follows both a green release gate and a green public-scan, never one of them.
